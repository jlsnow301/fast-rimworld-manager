# Fast rimworld manager

This is not ready AT ALL so please don't download this expecting it to work.

I made this repo entirely with agents and some of my own architectural opinions. 'but it's a slop repo!' - you bet, and I wouldn't even fault you for that objection. Here's the issue: I play Rimworld with over 1200 mods and the existing mod manager really struggles. I also have some free tokens from Github Copilot. You can see why this exists now. Part of it, well, is that I just want to see if it's possible.

## Local Development

You'll need [Deno](https://docs.deno.com/runtime/) and [Rust](https://rust-lang.org/learn/get-started/).  
Run `deno install` and `deno task tauri dev` 

## Storybook

Run `deno task storybook` to open Storybook at `http://localhost:6006`.
